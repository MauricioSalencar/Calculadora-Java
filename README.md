# Calculadora Java com tratamento de exceção 
Calculadora desenvolvida em Java com foco na prática de conceitos fundamentais da linguagem, utilizando tratamento de exceções (try/catch), orientação a objetos, estruturas de repetição, organização por packages e funcionalidade de reinício da aplicação.

📚 Conceitos praticados:
Try/Catch
Loops (while)
Packages
Classes e métodos
Validação de entrada do usuário
Controle de fluxo
